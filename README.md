# ModernityExtra

## About
ModernityExtra is a resource pack for Minecraft 1.12.2, which intended to supplement the [ModernityAdjunct resource pack](https://www.curseforge.com/minecraft/texture-packs/modernity-adjunct) with more mod resources.

Most of the resources in the pack are not created by us but backported from modern versions, so if you want to use them in other projects, you'd better check the original mod's license first. There are also some resources created by us, which follow MIT license. The customized ModernityAdjunct in /adjunct follows GNU.

There is not a release plan on CurseForge or Modrinth because of the countless license problems.

If you find any bugs or want to ask us for a mod's texture backport, see the issues page. PRs are welcome too.

## How to Get
For some reason, there will not be a new release for some time.

If you want to get this pack, click on the green " <> Code " button first, then click on " Download ZIP " to get a zip package of the repo.

Then, unzip the package in a proper path. Go to ModernityExtra-dev/main and compress the whole folder (Don't compress the folder itself!). You will get a new zip, which is the ModernityExtra itself.

Reproduce the steps with ModernityExtra-dev/adjunct path to get a modified version of ModernityAdjunct. If necessary, you can also make fix packs and addition packs. They contain fixes for some forked mods or provide you with a different style.

## How to Use
It is necessary to use the pack with [Modernity](https://www.curseforge.com/minecraft/texture-packs/modernity), which provides support for vanilla textures. As a opposite, it is not recommended to use it with [ModernityAdjunct](https://www.curseforge.com/minecraft/texture-packs/modernity-adjunct). Use our customized version instead.

If you love the beautiful ocean water texture in modern Minecraft, use [Ocean Water](https://www.curseforge.com/minecraft/texture-packs/ocean-water).

There is a recommended order to put so many resource packs. From the buttom to the top, the order should be:

Translation Packs (for non-English users) - Ocean Water - Modernity - ModernityAdjunct - ModernityExtra - fix & addition packs - other resource packs

If you are a non-English user and hate lang changes in ModernityExtra, put the lang pack above it.
